# Claude AI Guidelines for Smithwick Project

This document contains guidelines for Claude AI when working with this project.

## Formatting Guidelines

### Phone Numbers

The traditional US phone number format should be used for all phone numbers:

**Format:** `(XXX) XXX-XXXX`

**Example:** `(512) 555-1234`

### Addresses

For addresses, please link to the Google Maps listing for the entity in question if you can find it, otherwise link to the address itself.
